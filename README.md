# 持仓总览 v5 前端

基于 `demo-portfolio-v5.html` 开发的持仓总览前端应用，与 TradingDataHub API 完全集成。

## 🚀 功能特性

### ✅ 已完成
- **数据流优化**：页面加载时只调用一次批量查询 API
- **自动刷新**：30秒间隔自动更新数据
- **汇率换算**：支持 USD/CNY、HKD/CNY 实时换算
- **失败重试**：3次重试机制，失败后提示用户
- **本地存储**：模拟 SQLite 数据库，存储持仓和交易记录
- **完整UI**：基于原设计稿的完整界面实现

### 📊 核心指标
- 总资产（含现金）
- 总盈亏（YTD）
- 仓位比例
- 三年目标进度

### 📋 数据展示
- **权益类持仓**：美股/港股混合，支持排序筛选
- **ETF持仓**：指数基金持仓管理
- **机会识别**：亏损超过5%的加仓机会
- **风险提示**：持仓集中度、行业风险
- **现金管理**：资金分配与定投进度

## 🔧 技术架构

### 前端模块
```
portfolio-v5/
├── index.html          # 主页面
├── css/
│   └── style.css      # 自定义样式
└── js/
    ├── api.js         # TradingDataHub API 封装
    ├── calculator.js  # 计算逻辑（汇率换算、指标计算）
    ├── renderer.js    # 页面渲染
    ├── db.js          # 本地数据库（模拟）
    └── main.js        # 主程序逻辑
```

### 数据流
```
页面加载 → 本地数据库获取持仓 → 批量查询API → 汇率查询 → 前端计算 → 渲染
    ↑                                    ↓
自动刷新 ←─────────────── 30秒间隔 ←───────┘
```

### API 集成
- `POST /api/stock/quotes` - 批量股票查询（含汇率）
- `GET /api/stock/quote/{symbol}` - 单只股票查询
- `GET /api/forex/rates/common` - 常用汇率查询

## 🛠️ 使用方法

### 1. 启动 TradingDataHub
```bash
cd tradingdatahub
conda activate tradingdatahub
python run.py
```
服务运行在：http://localhost:8005

### 2. 打开前端页面
直接打开 `portfolio-v5/index.html` 或使用本地服务器：
```bash
cd portfolio-v5
python -m http.server 8080
```
访问：http://localhost:8080

### 3. 基本操作
- **刷新数据**：点击右上角刷新按钮
- **录入交易**：点击"录入交易"按钮
- **切换视角**：成本视角 ↔ 现价视角
- **排序筛选**：表格顶部筛选器
- **快速加仓**：点击股票行中的"+"按钮

## 🔄 自动刷新机制

### 触发条件
- 页面加载完成
- 手动点击刷新按钮
- 每30秒定时刷新
- 页面从隐藏变为可见

### 失败处理
1. **重试策略**：3次重试，每次间隔1秒
2. **降级方案**：显示上次成功数据
3. **用户提示**：Toast 错误提示，3秒后自动消失
4. **状态保持**：不清空页面数据

## 💰 汇率计算

### 支持货币
- **USD**：美元
- **HKD**：港币
- **CNY**：人民币

### 换算公式
```
HKDCNY = HKDUSD × USDCNY

美股市值(CNY) = 股数 × 股价(USD) × USDCNY
港股市值(CNY) = 股数 × 股价(HKD) × HKDCNY
```

### 数据源
- **USDCNY**：美元兑人民币
- **HKDUSD**：港币兑美元
- 来自 TradingDataHub 实时汇率接口
