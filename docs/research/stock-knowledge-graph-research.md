**目标**: 展示个股上下游关联公司（供应/竞争/投资关系）

## 一、免费数据源调研（更新版）

### 1.1 港股数据源

| 数据源 | 免费程度 | 覆盖范围 | 数据类型 | 获取方式 | 评价 |
|--------|----------|----------|----------|----------|------|
| **港交所披露易** | 免费 | 港股 | 公告、年报 | 官方API/网页 | ⭐⭐⭐ 权威，需繁体处理 |
| **东方财富网** | 部分免费 | 港股 | 产业链、关联公司 | 网页爬取 | ⭐⭐⭐ 数据较全，需爬虫 |
| **同花顺** | 部分免费 | 港股 | 产业链图谱 | 网页爬取 | ⭐⭐⭐ 有产业链专题页面 |
| **Longbridge** | 免费 | 港股/美股 | 基础行情 | API | ⭐⭐ 行情数据，无关联关系 |

### 1.2 美股数据源（重点发现）

| 数据源 | 免费程度 | 覆盖范围 | 数据类型 | 获取方式 | 评价 |
|--------|----------|----------|----------|----------|------|
| **SEC EDGAR** | 免费 | 美股 | 年报、关联交易、供应商披露 | 官方API | ⭐⭐⭐⭐ 最权威，需英文NLP处理 |
| **OpenCorporates** | 免费 | 全球 | 股权关系、控制关系、子公司 | API | ⭐⭐⭐ 股权图谱，非产业链 |
| **Yahoo Finance** | 免费 | 美股 | 基础信息 | API | ⭐⭐ 无直接关联数据 |
| **FMP (Financial Modeling Prep)** | 免费版 | 美股 | 财务数据、基础信息 | API | ⭐⭐ 有限免费额度 |
| **Alpha Vantage** | 免费 | 美股 | 行情数据 | API | ⭐⭐ 无关联数据 |

### 1.3 关键发现：美股供应链数据

**SEC EDGAR 的宝藏**：
- **10-K 年报**：包含 "Related Party Transactions"（关联交易）
- **供应商披露**：部分公司会披露重大供应商和客户
- **Risk Factors**：包含供应链风险描述
- **免费 API**：https://www.sec.gov/edgar/sec-api-documentation

**OpenCorporates 关系数据**：
- **控制声明**：所有权或投票权
- **子公司**：母子公司关系
- **分支机构**：本地办事处
- **股权份额**：部分所有权或投资持股
- **免费 API**：https://api.opencorporates.com/

### 1.3 推荐免费数据源组合（港美股专用）

#### 方案A：官方API + NLP（推荐）
```
美股: SEC EDGAR API + 年报NLP提取关联交易
港股: 港交所披露易 + 公告NLP提取
补充: OpenCorporates 股权关系
```
- **优点**: 数据权威、免费、覆盖港美股
- **缺点**: 需英文NLP处理，开发工作量大
- **工作量**: 3-4周（含NLP模型）
- **数据类型**: 
  - 供应关系（从年报提取）
  - 投资关系（从OpenCorporates）
  - 竞争关系（需算法推断）

#### 方案B：混合方案（平衡）
```
美股: SEC EDGAR（主要供应商/客户披露）+ Yahoo Finance（基础信息）
港股: 东方财富/同花顺爬虫 + 港交所公告
补充: 手动维护核心公司关系
```
- **优点**: 平衡成本与效果，部分自动化
- **缺点**: 港股爬虫需维护
- **工作量**: 2-3周

#### 方案C：手动维护核心图谱（MVP快速验证）
```
手动整理 Top 100 核心公司关系
美股: 从SEC EDGAR手动提取关键关系
港股: 从财报手动整理
```
- **优点**: 快速上线、数据准确、无爬虫风险
- **缺点**: 覆盖范围小，需持续维护
- **工作量**: 1周开发 + 持续维护

## 二、可视化方案调研

### 2.1 主流知识图谱可视化库对比

### 2.2 推荐方案

#### 首选：ECharts Graph
```javascript
// 示例配置
option = {
  series: [{
    type: 'graph',
    layout: 'force',
    data: [
      { name: '宁德时代', symbolSize: 80, category: 0 },
      { name: '天齐锂业', symbolSize: 50, category: 1 },
      { name: '特斯拉', symbolSize: 60, category: 2 }
    ],
    links: [
      { source: '宁德时代', target: '天齐锂业', relation: '上游供应' },
      { source: '宁德时代', target: '特斯拉', relation: '下游客户' }
    ],
    categories: [
      { name: '核心公司' },
      { name: '上游供应商' },
      { name: '下游客户' }
    ],
    roam: true,
    label: { show: true },
    force: { repulsion: 1000 }
  }]
}
```
- **优点**: 中文文档完善，示例丰富，集成简单
- **缺点**: 超大规模图性能一般（>1000节点）
- **适用**: 我们的场景（单股关联公司 < 100个）完全够用

#### 备选：AntV G6
```javascript
// G6 示例
const graph = new G6.Graph({
  container: 'mountNode',
  width: 800,
  height: 600,
  defaultNode: { size: 40 },
  defaultEdge: { style: { stroke: '#e2e2e2' } },
  layout: { type: 'force', preventOverlap: true }
});
```
- **优点**: 专为图可视化设计，布局算法丰富
- **缺点**: 学习成本略高于 ECharts
- **适用**: 需要复杂图算法时选择

## 五、推荐方案

### 5.1 数据源（免费 + 港美股）

**美股数据源**:
- **主数据源**: SEC EDGAR API（免费官方）
  - 10-K年报：Related Party Transactions
  - 8-K公告：重大交易披露
  - 提取：供应商、客户、投资关系
- **补充**: OpenCorporates API（免费）
  - 股权关系、控制关系、子公司

**港股数据源**:
- **主数据源**: 港交所披露易（免费官方）
- **补充**: 东方财富/同花顺（爬虫）

**手动维护**:
- 核心公司关系（持仓股票优先）

### 5.2 可视化
- **推荐**: ECharts Graph
- **理由**: 
  - 中文文档完善
  - 与现有技术栈（portfolio-v5 用 ECharts）一致
  - 学习成本低
  - 性能满足需求（<100节点）

### 5.3 开发顺序
1. **Phase 1**: 东方财富爬虫 + 基础图谱展示（1-2周）
2. **Phase 2**: 交互优化 + 美股支持（1周）
3. **Phase 3**: 智能推荐 + 社区数据（后续迭代）
